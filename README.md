# ULTRASOUND — Vessel Phantom Scan → 3D Reconstruction

Pipeline that scans a **vessel phantom** with a SmartUS B-mode ultrasound probe, segments the
anechoic (dark) vessel structures in every frame, and reconstructs them as an interactive
**3D surface mesh**. A full runnable walkthrough with example output images at each step is in
[`report.ipynb`](report.ipynb).

## Pipeline overview

```
SmartUS probe ──► MP4 video (data/video)
                     │  data/extract_frames.py
                     ▼
              per-frame PNGs (data/video2images/<stem>/)
                     │  2_segment/segment_vessels.py
                     ▼
        masks / red overlays / component JSON (2_segment/output/<stem>/)
                     │  3_construct/construct_3d.py
                     ▼
     3D voxel volume + marching-cubes surface mesh (3_construct/output/)
```

| Step | Folder / script | Description |
|---|---|---|
| 0 – Tracking *(optional)* | [`0_track/track_markers.py`](0_track/track_markers.py) | Streams 3D marker / rigid-body poses of the probe from an OptiTrack Motive system via a C++ wrapper DLL (`0_track/bin/motive_wrapper.dll`). Close `Motive.exe` first. |
| 1 – Acquisition | [`1_acquire/SmartUsDisplay.py`](1_acquire/SmartUsDisplay.py) | Live B-mode display + recorder driven by the vendor SDK (`usgfw2wrapper.dll`). All scan settings come from [`1_acquire/.env`](1_acquire/.env). Keys: `i` snapshot, `v` toggle video recording, `q` quit. |
| 2a – Frame extraction | [`data/extract_frames.py`](data/extract_frames.py) | Splits a recorded MP4 into one PNG per frame + metadata JSON. |
| 2b – Segmentation | [`2_segment/segment_vessels.py`](2_segment/segment_vessels.py) | Pure-OpenCV segmentation of anechoic vessels: blur → low-intensity threshold → morphological cleanup → interior detectors (A1/A2, erode-seed-dilate with border filtering) + a border-bulge detector for vessels cut off by the scan edge. Candidates are filtered by area, median intensity, solidity and elongation. |
| 3 – 3D construction | [`3_construct/construct_3d.py`](3_construct/construct_3d.py) | Stacks masks into a voxel volume with physical spacing (Z = scan direction, `--length-cm` over all frames; X/Y = in-plane, `--fov-cm` FOV), extracts the surface with marching cubes and renders it in PyVista. Mesh export to OBJ/STL/PLY supported. |

## Setup

1. Python 3.10+ (developed on Windows 11).
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Hardware steps need the prebuilt vendor DLLs that ship in this repo
   (`0_track/bin/motive_wrapper.dll`, `1_acquire/usgfw2wrapper.dll`) **and** the physical
   devices (OptiTrack system / SmartUS probe). Steps 2a–3 are pure Python and work on the
   already-recorded data.

## Running the pipeline

Run everything from the project root:

```bash
# Step 0 (optional, needs OptiTrack; close Motive.exe first)
python 0_track/track_markers.py --duration 10 --csv out/marker_log.csv

# Step 1 (needs the SmartUS probe connected)
python 1_acquire/SmartUsDisplay.py

# Step 2a - split a recorded video into frames
python data/extract_frames.py data/video/ultrasound_20260924_152247.mp4

# Step 2b - segment vessels in every frame
python 2_segment/segment_vessels.py

# Step 3 - interactive 3D view (r = toggle spin, s = screenshot, q = quit)
python 3_construct/construct_3d.py --video-stem ultrasound_20260924_152247

# Headless / export variants of step 3
python 3_construct/construct_3d.py --screenshot out.png --export-mesh vessels.obj
```

## Running the report notebook

`report.ipynb` is a self-contained, runnable report: it re-executes segmentation on an example
frame and rebuilds the 3D surface from the saved mask stack, showing example images at every
step (scanning, splitting, segmentation, 3D construction). No hardware required — only the data
already present in `data/` and `2_segment/output/`.

- VS Code: open `report.ipynb` → **Run All**
- or: `jupyter notebook report.ipynb` / `jupyter nbconvert --execute --inplace report.ipynb`

## Outputs

The raw videos (`data/video/`) are committed; everything below is generated by the
pipeline (git-ignored) and reproduced by running the steps above.

```
data/video/<stem>.mp4                     recorded B-mode video (in repo)
data/video2images/<stem>/                 one PNG per frame + <stem>_metadata.json
2_segment/output/<stem>/masks/            binary vessel masks (one per frame)
2_segment/output/<stem>/overlays/         red-highlighted overlays
2_segment/output/<stem>/json/             per-frame component statistics
2_segment/output/summary.json             whole-run summary
3_construct/output/                       screenshots + exported meshes (.obj/.stl)
```

## Known limitations (segmentation quality)

The segmentation does **not** come out clean on the current phantom dataset:

- The detected lumen is ragged/blob-like; mask edges follow speckle rather than the true vessel wall.
- The vascular structure in the middle of the image looks like noise — it is small, speckled and
  low-contrast, so the threshold-based detector cannot separate it reliably from background
  speckle and it **cannot be scanned/segmented properly** (irregular blob or missing in some frames).
- Frame-to-frame inconsistency makes the stacked 3D tube fragmented/broken (gaps along the scan axis).

Possible improvements: per-frame adaptive thresholding, stronger pre-smoothing matched to vessel
diameter, region-growing or a small CNN for the lumen, and true pose-based frame registration
using the `0_track` marker data instead of equal frame spacing.
